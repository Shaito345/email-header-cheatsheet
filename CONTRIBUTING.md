# Contributing

Pull requests and issues are welcome.

- Fix a wrong or outdated statement and link the source that proves it.
- Add a new header field or a new example. Use only reserved example domains like example.com, example.net and example.org, and documentation IP ranges like 192.0.2.0/24, 198.51.100.0/24 and 203.0.113.0/24.
- Never post a real header from a real case or a real person.
- Keep the plain style. Short sentences. One idea per line.
